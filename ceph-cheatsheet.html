OSD Management
OSD-Baum anzeigen
ceph osd tree ceph osd df tree
OSD ein-/ausschalten
ceph osd down 0 ceph osd up 0 ceph osd out 0 ceph osd in 0
OSD sicher entfernen
ceph osd safe-to-destroy osd.0 ceph osd destroy 0 --yes-i-really-mean-it ceph osd purge 0 --yes-i-really-mean-it
CRUSH-Gewicht anpassen
ceph osd crush reweight osd.0 1.0 ceph osd crush reweight-all
OSD-Performance testen
ceph tell osd.0 bench ceph tell osd.* bench
Scrubbing steuern
ceph osd scrub osd.0 ceph osd deep-scrub osd.0

Pool Management
Pools auflisten
ceph osd pool ls ceph osd pool ls detail rados df
Pool erstellen
ceph osd pool create mypool --autoscale-mode on # Alte Methode mit PG-Anzahl: ceph osd pool create mypool 128
Pool-Parameter setzen
ceph osd pool set mypool size 3 ceph osd pool set mypool min_size 2 ceph osd pool set mypool pg_autoscale_mode on
Pool-Typ: Replicated oder Erasure
# Erasure Coding Profil erstellen: ceph osd erasure-code-profile set myprofile \ k=4 m=2 ceph osd pool create ecpool \ erasure myprofile
Pool Snapshots & Statistiken
ceph osd pool stats mypool ceph osd pool mksnap mypool snap1 ceph osd pool rmsnap mypool snap1
Pool umbenennen / löschen
ceph osd pool rename old new ceph osd pool delete mypool mypool \ --yes-i-really-really-mean-it
💡 Für OpenStack: Pools volumes, images, vms, backups anlegen

RBD — RADOS Block Device
Image erstellen / auflisten
rbd create --size 10G volumes/myimage rbd ls volumes rbd info volumes/myimage
Image anhängen / trennen
rbd map volumes/myimage rbd showmapped rbd unmap /dev/rbd0
Snapshots verwalten
rbd snap create volumes/myimage@snap1 rbd snap ls volumes/myimage rbd snap rollback volumes/myimage@snap1 rbd snap purge volumes/myimage rbd snap rm volumes/myimage@snap1
Image klonen & schützen
rbd snap protect images/ubuntu@snap rbd clone images/ubuntu@snap \ volumes/new-vm-disk rbd flatten volumes/new-vm-disk
Image vergrößern / exportieren
rbd resize --size 20G volumes/myimage rbd export volumes/myimage /tmp/backup.img rbd import /tmp/backup.img volumes/restored
Features aktivieren/deaktivieren
rbd feature disable volumes/myimage \ object-map fast-diff deep-flatten rbd feature enable volumes/myimage layering
💡 Für OpenStack: exclusive-lock + layering Features aktivieren
📁
CephFS — Filesystem
Filesystem anzeigen
ceph fs ls ceph fs status ceph mds stat
Filesystem erstellen
ceph osd pool create cephfs_data ceph osd pool create cephfs_meta ceph fs new myfs cephfs_meta cephfs_data
CephFS mounten (Kernel)
mount -t ceph MON_IP:/ /mnt/cephfs \ -o name=admin,secret=KEY
CephFS mounten (FUSE)
ceph-fuse -m MON_IP:6789 /mnt/cephfs # oder via /etc/fstab: none /mnt/cephfs fuse.ceph \ ceph.id=admin,_netdev 0 0
Quoten setzen
setfattr -n ceph.quota.max_bytes \ -v 10737418240 /mnt/cephfs/dir setfattr -n ceph.quota.max_files \ -v 1000 /mnt/cephfs/dir

RADOS Gateway — S3 / Swift (RGW)
Benutzer verwalten
radosgw-admin user create \ --uid=user1 \ --display-name="Max Mustermann" radosgw-admin user info --uid=user1 radosgw-admin user list
Access-Keys verwalten
radosgw-admin key create \ --uid=user1 --key-type=s3 radosgw-admin key rm \ --uid=user1 --key-type=s3 \ --access-key=ACCESS_KEY
Buckets verwalten
radosgw-admin bucket list radosgw-admin bucket stats \ --bucket=mybucket radosgw-admin bucket rm \ --bucket=mybucket --purge-objects
Quoten & GC
radosgw-admin quota set \ --uid=user1 \ --quota-scope=user \ --max-size=50G radosgw-admin gc list radosgw-admin gc process

Maintenance & Cluster-Flags
Wichtige Flags setzen/löschen
ceph osd set noout # Vor Wartung! ceph osd set norebalance ceph osd set noscrub ceph osd set nodeep-scrub ceph osd unset noout # Nach Wartung
Alle gesetzten Flags anzeigen
ceph osd dump | grep flags
Balancer steuern
ceph balancer on ceph balancer off ceph balancer status ceph balancer eval
PG-Repair & Recovery
ceph pg repair 1.4a ceph pg dump | grep inconsistent ceph health detail | grep pg
OSD-Daemon-Optionen
ceph tell osd.0 config get osd_max_backfills ceph tell osd.* config set \ osd_recovery_max_active 3
⚠️ Immer noout setzen, bevor ein OSD-Host neu gestartet wird!
🔑
Auth & Keyrings
Keys auflisten
ceph auth ls ceph auth get client.admin ceph auth get-key client.admin
OpenStack-Client-Key erstellen
ceph auth add client.cinder \ osd "allow rwx" \ mon "allow r" \ mgr "allow rw" ceph auth get client.cinder \ -o /etc/ceph/ceph.client.cinder.keyring
Key entfernen
ceph auth del client.cinder
🔗
OpenStack Integration
Pools für OpenStack erstellen
ceph osd pool create volumes ceph osd pool create images ceph osd pool create vms ceph osd pool create backups rbd pool init volumes
Client-Keys für OpenStack
ceph auth add client.glance \ osd "allow rwx pool=images" \ mon "allow r" ceph auth add client.nova \ osd "allow rwx pool=vms,pool=volumes" \ mon "allow r"
ceph.conf Beispiel (OpenStack-Node)
# /etc/ceph/ceph.conf [global] fsid = CLUSTER_UUID mon_host = mon1,mon2,mon3 auth_cluster_required = cephx auth_service_required = cephx [client.cinder] keyring = /etc/ceph/ceph.client.cinder.keyring rbd_default_features = 1
Cinder Backend-Config (cinder.conf)
[ceph] volume_driver = cinder.volume.drivers.rbd.RBDDriver rbd_pool = volumes rbd_ceph_conf = /etc/ceph/ceph.conf rbd_flatten_volume_from_snapshot = false rbd_user = cinder rbd_keyring_conf = /etc/ceph/ceph.client.cinder.keyring
💡 Nova braucht ceph.client.nova.keyring auf allen Compute-Nodes
