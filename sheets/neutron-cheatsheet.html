Netzwerke & Subnetze
Netzwerke
openstack network list openstack network show private openstack network create private \ --provider-network-type vxlan openstack network create external \ --external \ --provider-network-type flat \ --provider-physical-network physnet1 openstack network delete private
Subnetze
openstack subnet list openstack subnet show mysubnet openstack subnet create \ --network private \ --subnet-range 10.0.0.0/24 \ --gateway 10.0.0.1 \ --dns-nameserver 8.8.8.8 \ --dns-nameserver 8.8.4.4 \ --allocation-pool start=10.0.0.100,end=10.0.0.200 \ mysubnet openstack subnet delete mysubnet
DHCP & IPv6
openstack subnet set --no-dhcp mysubnet openstack subnet create \ --network private \ --subnet-range fd00::/64 \ --ip-version 6 \ --ipv6-ra-mode slaac \ --ipv6-address-mode slaac \ mysubnet-v6
🔀
Router
Router verwalten
openstack router list openstack router show myrouter openstack router create myrouter openstack router set \ --external-gateway external \ myrouter openstack router add subnet myrouter mysubnet openstack router remove subnet myrouter mysubnet openstack router delete myrouter
Router Ports & Routen
openstack router show -c interfaces_info myrouter openstack router add route \ --route destination=192.168.0.0/24,gateway=10.0.0.254 \ myrouter openstack router remove route \ --route destination=192.168.0.0/24,gateway=10.0.0.254 \ myrouter
HA Router: openstack router create --ha myrouter (bei Neutron mit L3HA) erzeugt einen hochverfügbaren Router via VRRP.
🔌
Ports
Port-Operationen
openstack port list openstack port list --network private openstack port show myport openstack port create \ --network private \ --fixed-ip ip-address=10.0.0.50 \ myport openstack port create \ --network private \ --mac-address aa:bb:cc:dd:ee:ff \ myport openstack port delete myport
Port konfigurieren
openstack port set \ --security-group mysg \ myport openstack port unset --security-group mysg myport openstack port set --no-security-group myport openstack port set \ --allowed-address ip-address=10.0.0.0/24 \ myport openstack server add port myserver myport
🌍
Floating IPs
FIP verwalten
openstack floating ip list openstack floating ip create external openstack floating ip show 203.0.113.10 openstack floating ip delete 203.0.113.10
FIP zuweisen
openstack server add floating ip myserver 203.0.113.10 openstack server remove floating ip myserver 203.0.113.10 # An spezifischen Port binden: openstack floating ip set \ --port myport \ 203.0.113.10
🛡
Security Groups
Security Groups
openstack security group list openstack security group create websg \ --description "Web Server Security Group" openstack security group delete websg
Regeln hinzufügen
openstack security group rule list websg # SSH eingehend: openstack security group rule create \ --proto tcp --dst-port 22 \ --remote-ip 10.0.0.0/8 websg # HTTP/HTTPS: openstack security group rule create \ --proto tcp --dst-port 80 websg openstack security group rule create \ --proto tcp --dst-port 443 websg # ICMP (ping): openstack security group rule create \ --proto icmp websg # Ausgehend alles: openstack security group rule create \ --proto any --egress websg
SG entfernen
openstack security group rule delete openstack server remove security group myserver websg

QoS & RBAC
QoS Policy
openstack network qos policy list openstack network qos policy create 1gbit-policy openstack network qos rule create \ --type bandwidth-limit \ --max-kbps 1000000 \ --max-burst-kbits 10000000 \ 1gbit-policy openstack port set --qos-policy 1gbit-policy myport
RBAC (Netzwerke teilen)
openstack network rbac list openstack network rbac create \ --type network \ --action access_as_shared \ --target-project otherproject \ private
Quotas
openstack quota show --project myproject openstack quota set \ --networks 20 \ --subnets 40 \ --routers 10 \ --floating-ips 50 \ myproject
