Images auflisten & anzeigen
Übersicht
openstack image list openstack image list --public openstack image list --private openstack image list --shared openstack image list --community openstack image list --status active openstack image list --tag ubuntu openstack image show ubuntu-22.04
Filter
openstack image list --name ubuntu* openstack image list --format value -c ID -c Name -c Status openstack image list --property os_type=linux openstack image list --sort name:asc
⬆
Images hochladen
Upload (lokal)
openstack image create \ --file ubuntu-22.04.qcow2 \ --disk-format qcow2 \ --container-format bare \ --public \ ubuntu-22.04
Mit Eigenschaften
openstack image create \ --file ubuntu-22.04.qcow2 \ --disk-format qcow2 \ --container-format bare \ --min-disk 8 \ --min-ram 512 \ --property os_type=linux \ --property os_distro=ubuntu \ --property os_version=22.04 \ --tag ubuntu \ --tag lts \ ubuntu-22.04
Disk-Formate
# Gültige Formate: # qcow2 — QEMU/KVM (gängigste Wahl) # raw — uncomprimiertes Rohformat # vmdk — VMware Disk # vhd — Hyper-V VHD # vhdx — Hyper-V VHDX # iso — ISO-Image (bootbar) # aki/ari/ami — Amazon-Kernel/Ramdisk/Image
Deactivate / Reactivate
openstack image set --deactivate ubuntu-22.04 openstack image set --activate ubuntu-22.04
⬇
Images herunterladen & löschen
Download
openstack image save \ --file ubuntu-22.04-downloaded.qcow2 \ ubuntu-22.04
Löschen
openstack image delete ubuntu-22.04 openstack image delete img1 img2 img3
Import-Methoden (v2)
# Web-Download (Glance lädt direkt): openstack image create \ --import-method web-download \ --uri https://example.com/image.qcow2 \ --disk-format qcow2 \ --container-format bare \ myimage # Glance-direct (via staging): openstack image stage myimage < image.qcow2 openstack image import --import-method glance-direct myimage
🏷
Properties & Tags
Properties setzen
openstack image set \ --property hw_disk_bus=virtio \ --property hw_vif_model=virtio \ --property hw_scsi_model=virtio-scsi \ ubuntu-22.04 openstack image unset --property hw_disk_bus ubuntu-22.04
Nützliche Properties
hw_disk_bus=virtio # Disk-Bus hw_vif_model=virtio # NIC-Treiber hw_qemu_guest_agent=yes # QEMU GA os_require_quiesce=yes # Quiesce für Snapshots img_config_drive=mandatory # Config-Drive hypervisor_type=qemu # Hypervisor-Typ
Tags verwalten
openstack image set --tag lts --tag ubuntu ubuntu-22.04 openstack image unset --tag lts ubuntu-22.04
🤝
Sichtbarkeit & Sharing
Sichtbarkeit ändern
# Werte: public | private | shared | community openstack image set --public ubuntu-22.04 openstack image set --private myimage openstack image set --shared myimage openstack image set --community myimage
Image teilen
# Image mit Projekt teilen: openstack image add project myimage otherproject # Im Ziel-Projekt akzeptieren: openstack image set --accept myimage # Übersicht der Member: openstack image list --shared openstack image remove project myimage otherproject
community: Jeder kann ein Community-Image nutzen, ohne explizite Freigabe. Gut für Team-weite Basis-Images.
