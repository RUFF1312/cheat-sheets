Volumes
Auflisten & Anzeigen
openstack volume list openstack volume list --all-projects openstack volume list --status error openstack volume show myvol
Volume erstellen
openstack volume create --size 100 myvol # Aus Image (bootbar): openstack volume create \ --image ubuntu-22.04 \ --size 30 \ --type ssd \ --bootable \ bootvol # Aus Snapshot: openstack volume create \ --snapshot mysnap \ --size 100 \ vol-from-snap # Aus bestehendem Volume: openstack volume create \ --source myvol \ --size 100 \ vol-clone
Ändern & Löschen
openstack volume set --name newname myvol openstack volume set --size 200 myvol # nur vergrößern! openstack volume set --bootable myvol openstack volume set --read-only myvol openstack volume delete myvol openstack volume delete --purge myvol # inkl. Snapshots
🔗
Attach & Detach
Volume an Server
openstack server add volume myserver myvol openstack server add volume \ --device /dev/vdb \ myserver myvol openstack server volume list myserver openstack server remove volume myserver myvol
Attachment (Microversion)
openstack volume attachment create \ --connect \ --initiator iqn.1994-05.com.redhat:... \ myvol myserver openstack volume attachment list openstack volume attachment delete
Multiattach: openstack volume create --multi-attach --size 100 shared-vol erlaubt Attach an mehrere Server gleichzeitig (Volume-Typ muss multiattach unterstützen).
📸
Snapshots
Snapshots verwalten
openstack volume snapshot list openstack volume snapshot create \ --volume myvol \ --force \ mysnap openstack volume snapshot show mysnap openstack volume snapshot set --name newname mysnap openstack volume snapshot delete mysnap
Aus Snapshot erstellen
openstack volume create \ --snapshot mysnap \ --size 100 \ vol-from-snap # Snapshot zu Image konvertieren: openstack image create \ --volume myvol \ --force \ myimage
🔒
Backups
Backup erstellen
openstack volume backup create \ --name mybak \ --incremental \ myvol openstack volume backup list openstack volume backup show mybak
Restore
openstack volume backup restore mybak restoredvol openstack volume backup restore \ --volume myvol \ mybak openstack volume backup delete mybak
🏷
Volume Types & QoS
Volume Types
openstack volume type list openstack volume type show ssd openstack volume type create ssd openstack volume type set \ --property volume_backend_name=ceph \ ssd openstack volume type set \ --encryption-provider nova.volume.encryptors.cryptsetup \ --encryption-cipher aes-xts-plain64 \ --encryption-key-size 256 \ encrypted
QoS Specs
openstack volume qos create \ --consumer back-end \ --property total_iops_sec=5000 \ 5k-iops openstack volume qos associate 5k-iops ssd openstack volume qos list

Transfers & Quotas
Volume Transfer
# Volume an anderen Projekt übergeben: openstack volume transfer request create myvol # Gibt transfer-id und auth-key aus # Im Ziel-Projekt annehmen: openstack volume transfer request accept \ --auth-key XXXX \
Quotas
openstack quota show --project myproject openstack quota set \ --volumes 100 \ --gigabytes 10000 \ --snapshots 200 \ --backups 50 \ --backup-gigabytes 5000 \ myproject
Admin: Manage/Unmanage
# Externes Volume importieren: openstack volume manage \ --host cinder@lvm \ --name myvol \ # Cinder-Verwaltung entfernen (ohne löschen): openstack volume unmanage myvol
