Server auflisten & anzeigen
Übersicht
openstack server list openstack server list --all-projects openstack server list --status ERROR openstack server list --host esx01.example.com openstack server list -c ID -c Name -c Status -c Networks openstack server show myserver
Filter & Suche
openstack server list --name myapp* openstack server list --image ubuntu-22.04 openstack server list --flavor m1.large openstack server list --project myproject openstack server list --user alice
🚀
Server erstellen
Minimal
openstack server create \ --flavor m1.small \ --image ubuntu-22.04 \ --network private \ --key-name mykey \ myserver
Vollständig
openstack server create \ --flavor m1.large \ --image ubuntu-22.04 \ --network private \ --security-group default \ --key-name mykey \ --availability-zone az1 \ --user-data ./cloud-init.yml \ --property env=prod \ --wait \ myserver
Boot from Volume
openstack server create \ --flavor m1.small \ --block-device source_type=image,uuid=,\ dest_type=volume,volume_size=50,\ boot_index=0,delete_on_termination=true \ --network private \ myserver-bfv
Aus existierendem Volume
openstack server create \ --flavor m1.small \ --volume mybootvol \ --network private \ myserver-vol
⚡
Power-Operationen
Start / Stop / Reboot
openstack server start myserver openstack server stop myserver openstack server reboot myserver openstack server reboot --hard myserver
Pause / Suspend / Shelve
openstack server pause myserver # RAM eingefroren, CPU gestoppt openstack server unpause myserver openstack server suspend myserver # auf Disk gespeichert openstack server resume myserver openstack server shelve myserver # snapshot + Hypervisor frei openstack server unshelve myserver openstack server shelve-offload myserver
Löschen
openstack server delete myserver openstack server delete --wait myserver openstack server delete server1 server2 server3
🖥
Console & Logs
Console-URL
openstack console url show myserver openstack console url show --novnc myserver openstack console url show --spice myserver openstack console url show --serial myserver
Logs
openstack console log show myserver openstack console log show --lines 50 myserver
📐
Resize & Migration
Resize (kalt)
openstack server resize --flavor m1.large myserver openstack server resize confirm myserver # bestätigen openstack server resize revert myserver # zurücksetzen
Migration
openstack server migrate myserver # kalt (VM stoppt) openstack server migrate --live-migration \ --block-migration myserver # live (kein Stopp) openstack server migrate --live-migration \ --host esx02.example.com myserver
Rebuild (neues Image)
openstack server rebuild --image ubuntu-22.04 myserver openstack server rebuild --wait myserver
🎛
Flavors
Auflisten & Anzeigen
openstack flavor list openstack flavor list --public openstack flavor list --all openstack flavor show m1.large
Erstellen
openstack flavor create \ --vcpus 4 --ram 8192 --disk 80 \ --public \ m1.xlarge openstack flavor set \ --property hw:cpu_policy=dedicated \ --property hw:mem_page_size=large \ m1.xlarge
Löschen / Privater Zugriff
openstack flavor delete m1.oldflav openstack flavor set --private m1.secret openstack flavor access add --project myproject m1.secret

Keypairs
