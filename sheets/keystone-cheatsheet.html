Users
Übersicht
openstack user list openstack user list --domain Default openstack user show alice openstack user show --domain mydomain alice
User erstellen & ändern
openstack user create \ --domain Default \ --password mysecret \ --email alice@example.com \ --enable \ alice openstack user set --password newsecret alice openstack user set --disable alice openstack user set --enable alice openstack user delete alice
Passwort ändern (self)
openstack user password set \ --password newsecret \ --original-password oldsecret

Roles & Role-Assignments
Rollen verwalten
openstack role list openstack role show member openstack role create myrole openstack role delete myrole
Rolle zuweisen
# User + Projekt: openstack role add \ --user alice \ --project myproject \ member # User + Domain: openstack role add \ --user alice \ --domain mydomain \ admin # Gruppe + Projekt: openstack role add \ --group mygroup \ --project myproject \ reader
Zuweisungen anzeigen
openstack role assignment list openstack role assignment list --user alice openstack role assignment list --project myproject openstack role assignment list \ --user alice --project myproject openstack role remove \ --user alice --project myproject member

Groups & Domains
Groups
openstack group list openstack group create mygroup --domain Default openstack group add user mygroup alice openstack group remove user mygroup alice openstack group contains user mygroup alice openstack group delete mygroup
Domains

Implied Roles: openstack implied role create --implies reader member — member-Zuweisungen erben automatisch reader-Rechte.

Tokens
Token erzeugen & prüfen
openstack token issue openstack token issue -f value -c id # nur ID openstack token revoke # Scope wechseln (projekt-scoped): openstack token issue \ --os-project-name myproject openstack token issue \ --os-project-domain-name Default \ --os-project-name myproject
credentials.sh / openrc
export OS_AUTH_URL=https://keystone:5000/v3 export OS_PROJECT_NAME=myproject export OS_PROJECT_DOMAIN_NAME=Default export OS_USERNAME=alice export OS_USER_DOMAIN_NAME=Default export OS_PASSWORD=mysecret export OS_IDENTITY_API_VERSION=3 export OS_REGION_NAME=RegionOne

App Credentials
